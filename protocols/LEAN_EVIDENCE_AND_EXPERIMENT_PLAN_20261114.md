# Lean-SAM2 experiment plan and evidence

Status: selected retrospective PolypGen diagnostic; not a fresh benchmark. Respect the existing automatic one-shot detector/point prompt, no added re-detection or inference confidence threshold, and sequence 23's previously defined inset-excluded input on both automatic arms. All generated artifacts go to the user's Google Drive experiment directory. Never train on seq8, seq11, seq20 or seq23 for the proposed held-out diagnostic; patient-level independence across other sequences has not yet been established.

## Evidence already available

- The author Lean full-system versus native SAM2.1 comparison covers 21 videos and 2,012 post-prompt frames with matched initial GT mask, checkpoint and CPU FP32 runtime: equal-sequence present Dice 0.73446 versus 0.71904; paired sequence-bootstrap interval for Lean minus native [-0.03309, 0.06759]; empty false alarms 177 versus 163 of 323. It used the original Lean CPU implementation, for which a rotary-frequency discrepancy was identified later. It is exploratory and does not isolate TAMP, TCIM or TARR.
- Automatic four-video indexed comparisons use a different prompt and sequence 23 no-inset crop: original system versus raw token window matched present Dice seq8 0.852826/0.852516, seq11 0.273010/0.272518, seq20 0.193376/0.193376, seq23 0.038283/0.181825. The raw window also changes fused-history readout and temporal slots, so this is not a pure token-budget experiment. GT-prompt native/Lean historical numbers are unequal-prompt references.
- Pooled-anchor and early-prompt ablations have already been run. Neither shows a reliable general improvement. Do not duplicate them merely to produce a number.
- Seq23 cropped fixed-read deletions of 1024 selected older tokens produced no meaningful Dice change at frames 8, 20, 35, 48; they are conditional local interventions, not a full-video ablation. Channel gate has no verified trained checkpoint; uniform-weight interface gates are not a trained or predictive model.

## Current selected experiment: seq11 matched fixed-read deletion

Preselected frames 50, 100, 150, 200 are retrospective and may include absent frames. Reproduce the complete archived raw-window trajectory and require equality of every mask, positional/selection/memory trace and scored-frame file. Capture source tensors without extra model calls. In a fresh process, require exact attention/decoder/no-op mask reproduction and feature-plus-position source-span matching; preserve full conditioning, newest memory and pointer tokens. Remove exactly 1,024 older tokens per arm, equalizing memory attention key counts, and compare usage, foreground, foreground/background contrast, three-region, shuffled, RGB and spatially distributed methods. Two fresh replay processes must agree exactly; label masks are read only during independent scoring. Report per-frame no-op Dice, each deletion's Dice change, empty-frame false alarms and token overlaps. Such effects are conditional on other memory and attention normalization. They do not establish the quality of an online selector or a propagated improvement.
