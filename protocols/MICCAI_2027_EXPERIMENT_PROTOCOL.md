# MICCAI 2027 research protocol: contrast-based mask-to-memory correction

Status: design, not implementation, preregistration or evidence of novelty. Version 2026-11-14. The conference is the target, not a promise of publication. Existing seq11/20/23 and all previously inspected PolypGen results are exploratory and cannot be represented as an untouched test. The exact 2027 paper submission dates and rules must be verified from the official conference call when released.

## 1. Research question and candidate claim

Does a foreground–background contrast refiner using early and deep SAM2 image features improve automatic video-polyp masks, and does writing its corrected mask to the existing Lean-SAM2 memory encoder improve subsequent frames beyond output-only refinement? Preserve Lean's author token-pruning rule and the original detector for the main automatic comparison. No new redetection, confidence gating or inference threshold.

Tentative mechanism: frozen/pretrained SAM2 image features and original mask logits enter a spatially aligned, continuous residual correction module. It combines early spatial features, deep semantic features and automatic-prediction-derived foreground/background context through an explicitly specified channel aggregation/attention mechanism. Corrected logits can be output, fed to the memory encoder, or both. Do not call this CMSA-Net's CMA, the full CFBI model, or a validated novel mechanism. Record where object pointers, presence logits, original mask scaling/binarization and encoder tensors are computed; hold them fixed across the primary variants. No target ground truth at inference or memory writes. A module after the memory encoder is a separate secondary hypothesis, not part of the primary claim.

Closest prior work requires a maintained claim-difference table, including fine-grained SAM2 multiscale mask refinement (https://arxiv.org/abs/2502.09660), foreground/background matching in CFBI (https://arxiv.org/abs/2003.08333), and memory refinement for SAM2 few-shot segmentation (https://arxiv.org/abs/2505.14100). Video polyp work such as FreeVPS uses track-by-detect and filtering (https://arxiv.org/abs/2508.19705); do not quietly import those mechanisms under the current user constraints. Verify released code, checkpoint licensing and up-to-date work before claiming novelty. Distinguish parameter-free operations from pretrained feature models and from training-free end-to-end inference.

## 2. Baseline and factorial intervention

Primary baseline: verified automatic YOLO one-shot prompt + recent-window Lean-SAM2, fixed checkpoint, crop, preprocessing, prompt frame, memory budget and author pruning. The recent window is a project variant, not original Lean. Preserve the original detector checkpoint and independently audit prompt identity. Seq23 fixed no-inset crop is a retrospectively chosen layout rule; report its scope and do not extrapolate it to unknown layouts. Historical GT-prompt native SAM2/Lean/SAMURAI are unequal-prompt contextual references; do not rank them as automatic controls. The automatic-prompt SAMURAI experiment is currently incomplete.

After the refiner is trained and frozen, evaluate the same predeclared sequences and seeds in a 2x2 factorial design. All arms execute equivalent decoder/refiner computations where necessary for a fair comparison; only tensor routing differs:

| Arm | User-visible mask | Mask supplied to memory encoder |
|---|---|---|
| A | original logits | original mask |
| B | corrected logits | original mask |
| C | original logits | corrected mask |
| D | corrected logits | corrected mask |

B vs A estimates output-only correction on an identical unmodified memory trajectory if all other state, including pointers and object-presence decisions, is demonstrably unchanged. C vs A measures the consequences of corrected memory writes on subsequent frames; current output routing is held fixed, not the later trajectory. D vs B compares memory feedback when both show corrections, but trajectories differ after the first feedback. Declare whether initial conditioning writes are modified; primary proposal protects the original automatic conditioning prompt and corrects subsequent writes only. Exclude the conditioning frame from post-prompt primary Dice for all four arms; also report all-frame outcomes and pre-initialization frames separately. No absence detection or re-prompting is implied.

Mask threshold: retain the baseline's established logit-to-mask convention; no new tuned test-time gate. If original memory encoder consumes a transformed high-resolution logit or binary mask, apply the exact same native transform to the selected logits and verify tensor shape, dtype, range, resize/alignment and storage. Refiner must not modify learned SAM2 parameters or presence/object pointers in the frozen-backbone primary study. Capture and compare actual pointer, object-score, original and written mask tensors, memory source IDs, positional encodings and token counts. Treat any required difference as a protocol amendment, not an invisible implementation detail. Run unchanged-refiner/no-op and baseline reproduction checks before efficacy.

## 3. Controls for mechanism and capacity

All learned arms use matching decoder/adapter parameter counts to a documented tolerance, train/validation examples, optimization steps, seeds, backbone freeze policy and data augmentation; report exact parameter counts, FLOPs and training compute. Match loss, input resolution, preprocessing and output convention.

1. A: unmodified recent-window Lean.
2. Mask-only residual refiner: same decoder capacity/training, with image features masked or replaced by fixed constant; demonstrate it can be trained rather than an intentionally weak control.
3. Early-only, deep-only and early+deep fusion without foreground/background contrast.
4. Foreground-only and foreground–background contrast using the same features and head; use automatic predictions to compute prototypes. Define empty/degenerate cases as a continuous, predetermined numerical fallback, not a confidence or presence decision; report its frequency.
5. RGB contrast and spatially shuffled matched-feature controls using the same mask, head and training allowance. Report any mismatch where exactly equal capacity is impossible.
6. Existing occupancy-trained and utility-trained channel gates are historical diagnostics and are not substituted for a segmentation-trained feature-fusion module. Parameter-free statistics or SimAM may be a secondary control; never call untrained random attention a model candidate.
7. Model placement ablation: output-only, write-only and both via the 2x2 routing above. Optional post-memory-feature fusion must be separately implemented, trained and compared at equal attention-key counts; do not introduce a new pruning rule.
8. External comparators: SAMURAI under the exact automatic prompt/crop if its pending integration passes, and credible causal video-polyp baselines with licensed checkpoints; describe any retraining, extra data, parameters, prompt schedule and future-frame usage. GT-prompt versions remain a separate clearly labeled evaluation track. Noncausal CMSA/SASVi may be descriptive, not primary streaming controls.

## 4. Cohort, splits and leakage

Before tuning, inventory every dataset, source video, patient, center, timepoint, original filenames and checkpoint training data. Determine official data-use terms. Establish disjoint patient-level train/validation/test, with center or dataset external test where possible. Audit exact decoded duplicates and near-duplicate/adjacent video frames, patient and center metadata; record unresolved uncertainty rather than assuming sequence IDs imply separate patients. A checkpoint or detector with unknown overlap makes that cohort exploratory unless exposure is resolved; do not claim external generalization. Audit SAM2, Lean, detector and any extra model training exposure.

Seq11/20/23 were already selected and repeatedly inspected: retain them as development/failure-analysis cases and never market them as blinded confirmation. Do not train or tune on those videos in the initial pilot. Freeze a separate patient-disjoint final cohort before looking at its outcomes; seek independent video polyp data/centers and document whether it has representative absent intervals and dense masks. If no independent cohort is available, report a feasibility study and do not claim independent validation. Keep seq23's crop deterministic and inspect any foreground pixels discarded only as a post-hoc audit.

Training examples must resemble inference: generate masks using out-of-fold or otherwise training-isolated automatic rollouts with the same detector and state policy. Use both original and realistic corrupted predicted masks, including overextension, false positives, missing or empty masks, motion, blur and reappearance. Train only on training subjects; documented label-derived perturbations are training augmentation, never model inputs at test. Prevent labels from controlling prompt selection, feature extraction, source frames, temporal updates or evaluation frame inclusion. Use predeclared missing-prototype fallback; empty masks are valid. Track proportion of present/absent frames and miss severity; don't infer annotation completeness.

## 5. Experiments in order

A. Engineering: validate author repositories, revision/checkpoint hashes, feature strides/interpolation and channel order; compare captured early/deep tensors to native, mask logits before/after resize, object pointers, memory-write inputs and feature maps. Zero-residual/no-op must reproduce all masks, traces and model state on short real clips including nonzero initial prompt and seq23 crop. Unit-test missing/empty masks, image coordinates, source-frame rebasing and write-only/output-only routing. Run in two fresh processes and document platform/device determinism. Abort on mismatch.

B. Fixed-frame feasibility: freeze a representative predeclared development set with training-disjoint subjects, including observed seq11/20/23 failure examples as exploratory only. Use the same saved source states and outputs; do not propagate corrections. Run all controls with frozen models. Measure overextension, boundary accuracy, missed/zero-overlap cases and empty-frame behavior. Report all cases and any degenerate contrast fallback. Fixed-frame quality is not evidence of feedback efficacy.

C. Development full-video factorial: only a predeclared candidate that improves the primary fixed-frame control without material empty-frame degradation and passes engineering checks proceeds. 'Material' and minimum meaningful effect must be specified on training/validation data before looking at the final test, with power/precision feasibility. Run A/B/C/D on the same automatic prompts and frames. Outputs/logs/checkpoints and split hashes live in the user's Google Drive outputs/experiment; no results on local storage. Reuse existing baselines if the exact runtime, inputs, prompts, crop and source-frame sets match; otherwise document the mismatch and run the required matched control, respecting the user's earlier request not to rerun the two historical GT baselines.

D. Locked evaluation: freeze model/checkpoint, numerical conventions, selection, metrics, analysis code and all comparator outputs before labels are joined. Test on a held-out patient/center cohort not used for decisions, plus all four historically difficult sequences as separately identified exploratory cases. Repeat training across predeclared independent seeds and report every run; full-video inference reproducibility checks do not replace training-seed variation. Failure to meet the selection rule is a negative result; do not keep tuning against the final test.

## 6. Outcomes and statistical analysis

Co-primary outcomes for the primary A/D comparison: (i) mean per-video Dice on labeled-present post-initialization frames, then averaged equally across videos; (ii) per-video labeled-empty false-alarm rate where an alarm is any predicted foreground, averaged across videos with at least one empty frame. Report false-positive area per empty frame and count/denominator because a few pixels and a full-frame error are not clinically equivalent. Require a predeclared no-material-degradation margin for false alarms; estimate it on validation, justify it before final test, and evaluate confidence intervals against it. This is not a new inference threshold. If no margin or enough empty videos can be justified, report uncertainty and do not claim safety or non-inferiority.

Secondary: IoU, boundary Dice/surface distance with fixed physical or pixel tolerance and resolution stated, per-video foreground precision/recall, false-positive area, performance on predeclared size/occlusion/reappearance strata, worst-video changes, compute/FPS/latency and peak RAM/VRAM measured on a specified device with timing protocol. Separate inference from data loading, record warm-up, batch and repetitions; do not equate token budget with memory or throughput. For pre-prompt frames, count missed present targets separately and show full-frame metrics; do not use labels to decide initialization.

Statistics: sequence/patient is the unit, never individual frames or five groups. Use paired per-patient differences where patient identity is known; cluster sequences by patient and account for centers, with prespecified patient/center-stratified cluster bootstrap confidence intervals if sample size supports it. Report all per-sequence counts and effect sizes, uncertainty for both co-primary outcomes, and multiplicity correction for the declared co-primary/ablation family. For few clusters, use exact/permutation methods where defensible and show raw per-video differences; no misleading precision or formal non-inferiority claim. Compare A/B/C/D with prespecified planned contrasts; an interaction estimate needs enough independent videos and uncertainty, not frame-level p-values. Do not tune or select results on the test set. Report all seeds/failures and uncertainty.

Determine sample size and feasibility *before locking the test*: use independent-subject pilot variability, an a priori clinically/research meaningful Dice improvement and false-alarm margin, patient clustering, and power/precision simulation. No arbitrary numerical margin or sample count is asserted until data and uncertainty are available. If the available cohort is too small, downgrade to exploratory and seek data, rather than assert a MICCAI-ready result.

## 7. Contribution and stopping rules

A defensible claim requires (a) the full contrast/fusion module beats matched capacity/training controls on independent videos; (b) a benefit from writing the correction is distinguishable from output-only refinement with tolerable empty-frame behavior; (c) no hidden GT, future information, recropping advantage or changed token budget explains it; and (d) evidence covers more than the inspected difficult sequences. Report failure cases, boundary/empty-mask errors and selected versus full population results. If these conditions fail, retain a negative finding or revise using development data, never claim the original hypothesis was proven.

Deliver reproducible code, fixed configs, checksums, split/patient provenance where legally available, model cards, data permissions, deterministic/repeat notes, complete per-video results and an honest comparison table. No clinical efficacy or generalizability claim from the retrospective dataset alone. Follow the eventual official MICCAI 2027 call, ethics and data availability rules.
