# Cache-release mixed cross-fit handoff

This is a distinct, non-authorizing evidence format for the original 143-read
fresh grid. The original certified seq6 eager-gate observations are retained,
while a separately reconstructed full seq6 cache-release comparison and V3
MPS memory diagnostic are bound as compatibility evidence. Seq10, seq20,
seq22 and seq23 use their completed, independently reconstructed eager V2 audits. Seq8, seq11,
seq16, seq17, seq18, seq19 and seq21 require their own separately reconstructed
cache-release V2 reference, observer and full-sequence audit.

The handoff binds each sequence's source frame, frozen automatic prompt view
and ROI, label-metadata locator, feature/snapshot hashes, reference and
capture receipts, and sequence audit. Cache-release rows also bind both
sidecars, all four setup/frame allocator trace files, the exact seq6 proof and
the V3 diagnostic. No target mask is opened. All 143 identities must match the
frozen plan exactly once. Output remains `training_authorized=false`; the
bounded-v1 handoff/preflight must not be treated as equivalent to this format.

A passed seq6 comparison provides limited evidence on that sequence. It does
not prove eager-equivalent trajectories on other videos, nor does it establish
segmentation improvement. A separately versioned, independently reviewed
preflight, registry, probe and training/evaluation path must explicitly
reconstruct this exact handoff before any mixed-source training is permitted.
