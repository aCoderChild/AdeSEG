# Archived-prompt boundary factorial: sequences 6 and 10

This is a source-frozen feasibility plan for a separately authorized exploratory development comparison, not a blinded or independent test. The project owner states that each numbered sequence is a different patient; no patient-ID table has independently confirmed that statement. The frozen boundary refiner used seq2/3/4/5/12/13/14 for training and seq9/15 for validation; seq6 and seq10 are distinct sequence IDs. Both target sequences have been previously inspected: seq6 contributed training reads and seq10 validation reads to earlier, different refiner studies. They have adjacent-looking numeric source prefixes, whose meaning remains unresolved. Previous method selection and detector/checkpoint exposure limit the interpretation even under the owner's patient mapping.

Select exactly seq6 and seq10 from the existing positive-sequence manifest by identity, before new mask outcomes. Reuse each recorded `prompt_refined.png`, automatic box, points, detector settings, checkpoint and prompt ordinal from the archived cohort; do not call the detector, infer patient IDs from filenames, use ground truth at inference, add redetection, introduce a new threshold/gate, or change token pruning. Run all four output/memory A/B/C/D routing variants only after a separately reviewed runtime, short MPS gate and independent artifact audit are in place. Initialization and earlier frames must be reported separately; do not exclude cases on the basis of outcome.

The new image-only preflight verifies archived chain/receipts, source frame index and byte hashes, image dimensions and prompt/mask geometry. In addition to binding the existing frozen train/validation preflight, it computes raw-byte and decoded-RGB image hashes across **all input frames** in those nine train/validation sequences and both targets, rejecting identical images across different sequence IDs. It does not open annotation-mask files or parse archived per-frame outcome values; it reads raw archived metadata bytes to hash them and selectively extract image identities. The existing manifest loader checks mask-file existence without opening them, so this is an annotated-manifest experiment, not deployment on an unlabeled video. The CPython mask-open guard is not a native-code security boundary. This does not detect near-duplicates, establish source/patient provenance, or prove the detector/backbone never trained on a patient. No inference is authorized solely by a successful preflight.

Separately, seq1 and seq7 have no archived automatic prompt and the earlier anchor metadata records no foreground mask. Do not infer clinically absent or fabricate a ground-truth prompt. If a new detector-only study is designed, freeze its model, predeclared source order and original detector settings, record all calls and frames before first initialization, and preserve no-detection cases as empty prediction outputs instead of excluding them. The historical protocol tests chronological images until first detection, then initializes exactly once and performs no later redetection; user restrictions prohibit adding a new redetection strategy or threshold. A detector run requires its own label-free provenance, prompt and identity checks, and is not implemented by this preflight.
