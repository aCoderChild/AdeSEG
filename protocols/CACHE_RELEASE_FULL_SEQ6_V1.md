# Fixed-cache-release full seq6 compatibility preparation

This separate source-bound pipeline prepares one full seq6 engineering comparison. It does not alter the frozen eager or bounded runs, and execution is enabled only for the independently reviewed, supervised seq6 attempt. It requires reconstruction of both the seven-frame bounded-loader proof and the completed MPS memory diagnostic V3, bound to the same warm certificate. A short diagnostic is not proof of full-video safety.

The reference and observer are separate fresh MPS processes with identical automatic archived box, points and conditioning mask, checkpoint, bounded loader and Lean token policy. At fixed points after model load, state initialization and prompt warmup, and after each frame output is consumed and saved, both synchronize and call `torch.mps.empty_cache()`. This is an unconditional experimental allocator operation, not a new segmentation threshold, detector, redetection or model gating policy. Before/after system-available RAM, process RSS, MPS live tensors and driver allocations are recorded; actual resource violations stop immediately, as does the existing sampled supervisor at its unchanged 4-GiB RAM floor, 6-GiB RSS cap and dynamic 26-GiB-plus-unwritten-payload disk reserve. Sampling is not a hard limit against transient spikes. Partial logs, frozen source snapshots and telemetry remain in Drive. No target labels are read.

The independent auditor validates source snapshots, proofs, sample coverage, telemetry, guards, all predicted masks, named traces and prompt features, plus decoder captures at the planned frames. It compares full seq6 outputs and traces to the phase-bound historical eager reference and overlapping observations including frames 24 and 90. Floating tensors use `rtol=1e-5, atol=1e-6`; named traces are checked exactly. Mask compatibility uses a predeclared per-frame agreement Dice of 0.995, with both-empty 1. This is an engineering agreement criterion, not ground-truth Dice or a model gate; a tiny difference in an otherwise empty mask can conservatively fail it.

A passing seq6 test does not establish full seq11 compatibility, physical memory benefit, segmentation accuracy or full-model state identity. It does not authorize seq11 capture or mixed-source training. A separately versioned handoff and training preflight must bind this new source/allocator schedule and any future seq11 evidence before such data can be used. Previously inspected patients remain exploratory.
