# Post-hoc boundary-objective control study

This is an exploratory follow-up selected after prior seq9/15 validation outcomes were inspected. It is not preregistered, blinded, patient-independent, or a full-video evaluation. It repeats the regional boundary-objective reference and compares equally parameterized global-channel, descriptor-roll and spatial-shuffle controls. All models use the same frozen 164/50 MPS captures, optimizer, order, seed, 10 epochs, initialization and corrected CMSA-inspired boundary objective as the prior factorial.

The global arm uses full-image average/max channel pooling, descriptor-roll uses the existing fixed channel permutation of foreground/background descriptors, and spatial-shuffle uses the V3 fixed shared spatial bijection before region prototypes and contrast. A bijection is not information destruction; the spatial control disrupts feature/mask alignment. The reference is a same-run reproduction to identify drift. The RGB input is not involved. The loss and its 31-native-pixel window are described in `CMSA_BOUNDARY_LOSS_PILOT_V1.md`.

All sources and data identities must be frozen before training. Reproduce the equal initial state and check CPU/MPS output, loss, gradients and native-sized masks on the three training-only probes from the earlier factorial. Each of four arms freezes all 50 predictions without opening validation masks. Independently replay all 400 frozen baseline/refined masks without label access; only then open labels in a separate scorer. Report all results and the previous same-objective no-contrast/mask-only arms separately, with per-video counts, mean Dice, pixel-based boundary F and labeled-empty false alarms. No observed effect alone authorizes live video or claims independent validation.
