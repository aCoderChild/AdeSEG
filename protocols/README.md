# Experiment protocols

- [Three-fold fixed-read study](BOUNDED_CROSSFIT_FIXED_READ_3FOLD_V1.md):
  the current channel-value evaluation, including fold assignment, fixed
  schedule, output freezing and guard requirements.
- [Warm unified cross-fit](EXPLORATORY_WARM_UNIFIED_CROSSFIT_V1.md):
  capture and provenance background; its earlier five-fold schedule is
  superseded by the three-fold protocol.
- [Boundary refiner video audit](BOUNDARY_FULL_VIDEO_EXPLORATORY_AUDIT_20261115.md):
  earlier candidate, routes and exploratory evidence.
- [Methods and evidence](../docs/METHODS.md): architecture and interpretation.

Other versioned protocol records document previous investigations and source
provenance. Preserve a record when a saved experiment refers to its path or
hash; a historical record is not an active experiment instruction.

For the current method and comparators, start with the links above and
[the comparator audit](COMPARATOR_AUDIT_2026_11.md). JSON files define
versioned cohorts, configurations or evidence contracts; they are not all
active run instructions. The project workflow catalog is available with
`python -m workflows --list`.
