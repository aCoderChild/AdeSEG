Ablation · is the heuristic necessary?

Heuristic reliability rt vs a fixed constant (r = 0.5), at every prompt schedule

Same 23 sequences · same 2,225 frames · same YOLO prompt schedule as each heuristic run above — only the memory blend weight changes. select_reliability() either returns the full heuristic (mask quality, box confidence, boundary, blur, object presence, plausibility penalties) or a constant passed via --fixed-reliability 0.5. Now run at all three strides, isolating whether the heuristic's five weighted signals earn their complexity over a naive constant blend — and whether that answer changes with prompt sparsity.

≈ tiedstride 1 (dense) · ΔDice −0.0002
−0.088 Dicestride 5 · heuristic wins

Headline: the heuristic is unnecessary at dense prompting but becomes clearly necessary once prompting goes sparse. The gap is almost entirely on unprompted frames — where memory alone must carry the mask across a gap with no fresh box to anchor it.

Note the split: on prompted frames, heuristic and fixed are within noise at every stride (a fresh YOLO box anchors the mask regardless of blend weight). The entire heuristic-vs-fixed gap lives on unprompted frames, and it widens with gap length — exactly where a constant blend can't adapt to whether the carried-over memory still looks trustworthy.

seq12 outlier: at stride 5, fixed collapses to Dice 0.2260 vs heuristic 0.7514 (Δ = −0.5255) on this single 250-frame sequence — the largest single-sequence effect in the whole ablation, and it alone accounts for a large share of the stride-5 aggregate gap. At stride 10 the same sequence drops to 0.1138 (fixed) vs 0.4629 (heuristic), Δ = −0.3490. Worth a closer look at seq12's frames to see what specifically the heuristic is catching there that a constant blend misses.

Verdict: conditionally supported. Not needed at stride 1 (statistically indistinguishable from a constant, ΔDice = −0.0002 global). Clearly needed at stride 5 (ΔDice = −0.0878) and stride 10 (ΔDice = −0.0663) — in both cases driven almost entirely by unprompted frames, and 12–13 of 23 sequences favor the heuristic by more than 0.01 Dice vs only 6–7 favoring the fixed weight. The heuristic's value scales with how long memory has to survive without a fresh box.
