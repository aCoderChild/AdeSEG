# AdeSEG research architecture: automatic video polyp segmentation

**Status (2026-11): active multiscale memory-write study; not a validated
end-to-end adenoid-segmentation system.** PolypGen colonoscopy sequences are
a development proxy, **not** clinical nasopharyngeal/adenoid data.

This document distinguishes the active **FGPI + Lean-SAM2 + early-FPN
memory-write enrichment** hypothesis from the older **FGPI/RMFA/TTMR**
experiments. They are separate research tracks and must not be described
as a single already-implemented model.

## 1. Active question and intended processing order

Let \(\{I_t\}_{t=0}^{T-1}\) be a video, and let \(Y_t\) denote a reference
mask available **only for training and offline evaluation**.

**RQ1 — Initialization.** A detector can provide a box \(b_0\);
feature-guided prompt initialization (FGPI) proposes positive and negative
points in addition to the box. This RQ is a separate experimental track.
The current Lean memory-fusion video runner does **not** execute YOLO or
FGPI inline. It reads a **frozen automatic mask prompt** generated by an
external producer. A new dedicated
[`export_lean_fgpi_prompts`](../../scripts/export_lean_fgpi_prompts.py)
stage now performs YOLO-box/FGPI initialization with the **same pinned
Lean-SAM2 Hiera-B+ image/FPN backbone**, and writes an authenticated,
GT-free automatic-mask receipt. This creates a staged, reproducible
YOLO-to-Lean input path, but **end-to-end real-GPU validation and performance
gains remain unestablished**. Inference alone is not proof that FGPI helped.

**RQ2 — Multiscale temporal-memory representation.** After a current
frame has been segmented by native Lean-SAM2, a small trainable adapter
combines earlier image-encoder-derived/FPN levels with the **native
mask-conditioned memory encoder output**, and returns an identically
shaped residual-enriched memory feature map.

**RQ3 — Efficient temporal memory.** The enriched memory is written to
Lean-SAM2's **existing** temporal memory bank. Native TAMP/TCIM/TARR,
token pruning, positional encodings and token budgets are not replaced
by a new selector. RQ3 evaluates robustness and selection behavior under
the native memory-management policy; it does **not** claim TTMR is used
by the active fusion runner.

## 2. Causal frame pipeline

For non-conditioning frame \(t\) in propagation, let
\(F_t^{(0)}\), \(F_t^{(1)}\), \(D_t\) denote the early
SAM2 image-encoder/FPN levels and deepest image feature. In the pinned
Hiera-B+ Lean build, the runtime early maps are projected to **32/64
channels by SAM2's existing decoder feature projections**; the native
memory encoder output has **64 channels**. These are *not* intermediate
activations of the memory encoder.

\[
\begin{aligned}
(F_t^{(0)},F_t^{(1)},D_t)&=\operatorname{ImageFPN}(I_t),\\
H_t&=\operatorname{MemoryAttention}(D_t,\mathcal B_{<t}),\\
\widehat Y_t&=\operatorname{MaskDecoder}
 (H_t,F_t^{(0)},F_t^{(1)},P_t),\\
M_t&=\operatorname{NativeMemoryEncoder}(D_t,\widehat Y_t),\\
\widetilde M_t&=
 M_t+\Delta_\theta(F_t^{(0)},F_t^{(1)},M_t,\widehat Y_t).
\end{aligned}
\]

The adapter spatially **area-pools** and **projects** both early
feature levels onto the native memory grid, then uses trainable
convolutions and a **bounded zero-initialized residual output**.
It does **not** simply concatenate extra tokens into the memory bank,
increase the memory-channel count, or replace the deep image feature
before segmentation. The output memory \(\widetilde M_t\) is used
**on subsequent frames**, not to change the already-produced
\(\widehat Y_t\).

By default the initial conditioning frame's memory and initial target
anchors remain native; the first later non-conditioning memory write
can be enriched. Lean's target-anchor scoring and memory pruning
occur when historical memories are **read**, not as a new fusion step
during the same write.

## 3. Mathematical and software invariants

| Quantity | Native shape | Fusion contract |
|---|---|---|
| Early FPN levels | \(B \times 32 \times H_0 \times W_0\), \(B \times 64 \times H_1 \times W_1\) | Pooled/projected at memory grid; original inputs preserved |
| Deep image feature | \(B \times 256 \times H_2 \times W_2\) | Used by native SAM2 memory attention and memory encoder |
| Native memory | \(B \times 64 \times H_m \times W_m\) | The residual has precisely this shape |
| Enriched memory | \(B \times 64 \times H_m \times W_m\) | Same channel/grid/token count and original positional encoding |
| Target anchor | \(K \times 64\) | Native initial-memory reference; similarity is measured, not assumed invariant |
| Predicted mask | \(B \times 1 \times H \times W\) | Inference prediction only; **never** target \(Y_t\) |

In the default configuration, each residual element is bounded by
\(\alpha\max(\operatorname{Std}(M_t),10^{-6})\) with \(\alpha=0.25\).
The no-object gate exactly preserves native memory on predicted absence.
These invariants support **shape compatibility and causal operation**;
they do **not** establish better Dice, higher retention quality or the
same resident token count over an entire video.

For proofs with assumptions, pinned source-level evidence and remaining
risks, see [the memory-enrichment architecture audit](LEAN_MEMORY_ENRICHMENT_AUDIT.md).

## 4. Implemented training and evaluation boundaries

- **Training:** same-frame TRAIN-only oracle-memory distillation
  (\(\widetilde M_t\) approximates memory obtained from a TRAIN GT mask),
  plus native-memory preservation. By default, the oracle correction is
  **projected into the bounded residual's feasible range**; the original
  raw oracle objective is an explicit separate control. This is **not**
  temporal backpropagation, a short-horizon segmentation loss, or direct
  optimization of TAMP.
- **Inference:** video runner begins from a **precomputed frozen automatic
  mask prompt**. During propagation it reads image features and predicted
  masks only. It does not use video labels.
- **Evaluation:** independent offline post-prompt Dice/IoU scoring from
  frozen PNGs, plus GT-empty false-alarm reporting, paired video-level
  comparisons, memory-write telemetry, storage counts and optional
  native TAMP retained-index overlap. Unpromptable videos and GT-positive
  frames without predictions are explicitly counted, and all-negative
  cohorts report false alarms with positive Dice marked **undefined**.
  Source-split auditing, real DEV GPU smoke and frozen TEST selection
  are separate, mandatory validation stages before paper claims.
- **Attribution:** controls \`full\`, \`no_early\`, \`early0_only\`,
  \`early1_only\`, \`no_mask\` are trained **separately** and evaluated
  with identical backbones and frozen prompts.
- **Limitations:** the GT-conditioned teacher is a surrogate target;
  early spatial detail is downsampled; a native-conditioning anchor may
  compare differently with enriched memory; and the source-group split
  must be reviewed for patient/source independence.

Primary runnable protocol:
[Lean memory-fusion experiment preflight](../experiments/LEAN_MEMORY_FUSION_PREFLIGHT.md).

## 5. Legacy research track — FGPI / RMFA / TTMR

The following previously implemented or proposed modules remain available
for independent reproduction, **but are not silently enabled** in the
active Lean memory-fusion runner:

- [FGPI](FGPI.md): detector-conditioned feature-guided prompting; its
  video runner may use a different medical SAM2 backbone.
- [RMFA](RMFA.md): multiscale region-aware **output-logit refinement**
  after segmentation, not the active **memory-write** fusion adapter.
- [TTMR](TTMR.md): a proposed target-aware memory **selector**; not
  interchangeable with native Lean-SAM2 TAMP.

Using several modules together would require a new explicitly specified,
source-pinned and ablated end-to-end integration. Never describe the
active memory-fusion experiment as an already integrated RMFA+TTMR model.

## 6. Literature and related methods

- [SAM 2](https://arxiv.org/abs/2408.00714): native streaming
  memory-conditioned video segmentation.
- [CMSA-Net](https://github.com/wangtong627/CMSA-Net): motivates
  complementary spatial scales but uses **causal cross-frame multi-scale
  attention**. The active adapter borrows the *spatial multiscale idea*,
  not the paper's aggregation operator.
- [Lean-SAM2](https://arxiv.org/abs/2607.19811): native TAMP/TCIM/TARR
  reference implementation. This study preserves their mechanisms.

**Claims that still require GPU/video data:** improved propagation,
actual target discrimination, improved TAMP selection, reliable
YOLO/FGPI-to-Lean compatibility, latency/VRAM trade-offs, and
generalization to actual adenoid imagery.
